# Security

## Reporting

Do not open public issues containing tokens, Telegram sessions, cookies, phone
numbers, private chat exports, or other personal data. Report security issues to
the repository owner through GitHub Security Advisories.

## Secrets

Never commit `.env`, `*.session`, browser profiles, cookies, SQLite databases,
Obsidian vaults, exported spreadsheets, or production logs. Rotate a credential
immediately if it is accidentally exposed.
